# Facebook media intake (pending inspection)

Source: the list of Syndy Emade Foundation Facebook links supplied for the media-integration brief.

**Status: nothing from this list is on the website yet.** Facebook is blocked from the build environment
(network policy 403, Firecrawl does not support facebook.com, and none of the photos are in the Web Archive),
so no asset could be opened or visually inspected. The brief forbids classifying from a URL alone, so every row
below is `pending: not inspected`. Batches group IDs that were uploaded together; that is a hint for review,
not a classification.

Totals: 92 photo links · 88 unique photos · 4 duplicates · 4 share links (3 videos, 1 post).

Duplicates (listed twice, keep one): 1070497749808060, 1229237300600770, 1071170826407419, 1071171016407400

## How to unblock

Download the photos from Facebook (Page → Photos → open each album → ⋯ → Download album) and put them in a Google
Drive folder shared with the account connected to this project, or upload them to the session. Name the folder after
the activity if known (e.g. `2023-12 Christmas Douala`). With the files, each asset will be inspected, matched to an
existing page and section, given alt text and captions, optimised, and added. Identifiable children and vulnerable
adults stay unpublished until consent is confirmed.
